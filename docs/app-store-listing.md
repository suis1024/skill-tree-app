# App Store Connect 提出用テキスト一式

App Store Connect の「アプリ情報」「バージョン情報」に貼り付けるテキストの
ドラフト。文字数制限ぎりぎりまで使わず、余白を残してある。

最終更新: 2026-05-05

---

## アプリ名 (最大 30 文字)

```
Skill Tree Shooter
```

(18 文字。日本語ストアでも英語表記でいく。短くて検索に強い)

---

## サブタイトル (最大 30 文字)

```
撃って稼いで強くなる、ローグライト
```

(15 文字。サブタイトルは検索インデックスに含まれるので
 「ローグライト」「ローグライク」を入れる)

---

## プロモーションテキスト (最大 170 文字、後から自由に変更可)

```
全方位シューティング × ローグライト。死んでもコインは持ち帰り、スキルツリーで永続強化。
10ステージ制覇を目指せ。操作は移動だけ、武器は自動発射でサクッと遊べる。
```

---

## 説明文 (最大 4000 文字)

```
Skill Tree Shooter は、サクッと遊べる全方位シューティング × ローグライトです。

操作は「移動」だけ。武器は自動で発射され、ジョイスティックでひたすら
逃げ回りながら敵を倒していきます。死んでも稼いだコインは全額持ち帰り、
スキルツリーで永続強化。次のランではもっと長く、もっと強く戦えます。

■ ゲームの特徴

・操作は移動だけ。1 プレイは数分〜10 分程度
・10 ステージ + 各ステージにボス戦
・25 種以上のスキルツリーで自由にビルド
・武器追加スキルで爆弾、サンダー、ホーミング、オービタルが解放
・「死ぬ → 強くなる → また挑戦」のローグライト中毒ループ

■ こんな人におすすめ

・隙間時間にサクッと遊べるアクションが欲しい
・Vampire Survivors / Brotato 系のローグライトが好き
・スキルを取って自分なりのビルドを組むのが楽しい

■ プライバシー

本アプリは外部サーバーと一切通信しません。広告 SDK や
解析ツールも入っていません。すべての進捗は端末内にのみ保存されます。
詳細は本アプリのプライバシーポリシーをご覧ください。

──

10 ステージのクリアを目指して、自分だけのビルドを完成させよう。
```

(約 600 文字。3000 文字以上残してあるので、必要に応じて
 スクリーンショット解説や Tips を追加できる)

---

## キーワード (カンマ区切り、合計 100 文字まで)

```
ローグライト,ローグライク,シューティング,STG,アクション,survivor,brotato,スキルツリー,ヴァンサバ,放置
```

(99 文字。サブタイトルとアプリ名で既にカバーされる単語は省く。
 「ヴァンサバ」「brotato」など類似ジャンルの俗称・固有名詞を入れて検索流入を狙う)

---

## カテゴリ

- プライマリ: **ゲーム > アクション**
- セカンダリ: **ゲーム > アーケード**

(「アクション」「アーケード」がローグライト系の定番枠)

---

## 年齢区分 (Age Rating)

App Store Connect の質問に対する回答:

| 項目                                | 回答     | 備考 |
|------------------------------------|---------|------|
| カートゥーンまたはファンタジーの暴力 | **頻繁/極度** | 幾何学図形の敵を撃って爆発させる |
| 写実的な暴力                        | なし    | 写実的描写なし |
| 性的描写                            | なし    | |
| 不適切な言葉                        | なし    | |
| 模擬ギャンブル                      | なし    | |
| 恐怖描写                            | なし    | |
| アルコール・タバコ・薬物            | なし    | |
| 医療・治療情報                      | なし    | |

→ **想定 Age Rating: 9+ または 12+**
   (カートゥーンの暴力「頻繁」だと 9+、「極度」だと 12+。
   実際には抽象的な弾と図形しか出ないので 9+ が妥当)

## サポート URL / マーケティング URL

サポート URL は必須、マーケティング URL は任意。
当面は両方ともプライバシーポリシーと同じ legal リポの
別ページ (例: support.html) を立てる。
仮で当面はプライバシーポリシー URL を流用する。

```
https://suis1024.github.io/skill-tree-shooter-legal/privacy.html
```

(後で skill-tree-shooter-legal/support.html を追加する)

## App Privacy (データ収集の宣言)

App Store Connect の「App Privacy」セクション:

- **データを収集していない** を選択
  - 理由: 完全ローカル、外部送信ゼロ、解析 SDK ゼロ
